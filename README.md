# Quiz App

A simple interactive quiz application built with Node.js and Bootstrap.
The app displays multiple-choice questions, plays sounds for feedback,
and loads questions dynamically from JSON files.

## 🚀 Features

- Multiple-choice quiz questions
- Dynamic question loading from JSON
- Sound effects for correct and wrong answers
- Score tracking
- Responsive design using Bootstrap

## 🛠️ Technologies Used

- Node.js
- Bootstrap 5
- HTML5
- CSS3
- JavaScript
- JSON (for quiz data)
- Audio (for feedback sounds)
